專案目標

先完成最小可運行流程，再往完整航線任務擴充。

1要解決什麼

讓無人機在模擬環境中，依照航點順序自動飛行，並在任務結束後安全返航或降落。

2成功標準

能從電腦端連到模擬飛控，並穩定完成解鎖、起飛、返航這三個核心動作。

技術組合

選用的是業界常見、資料也最多的組合。

A模擬器

使用 SITL 搭配 Gazebo 或 jMAVSim，模擬無人機飛行環境。

  • SITL（Software In The Loop）
  • 可先用 jMAVSim 做快速驗證

B飛控韌體

用 PX4 或 ArduPilot 模擬飛控邏輯，提供任務執行能力。

  • PX4
  • ArduPilot

C控制層

透過 MAVLink 與 MAVSDK-Python，從 Python 控制無人機行為。

  • MAVLink
  • MAVSDK-Python

執行流程

先從連線與基本動作開始，不要一開始就跳到完整任務。

初始化連線

連接模擬中的無人機，確認可以收到狀態資料。

解鎖並起飛

先確認 arm 與 takeoff 可以穩定執行。

上傳航點

把設定好的航點送到飛控系統。

執行航線

讓無人機依序飛到每個航點。

返航／降落

任務結束後返回起飛點或直接降落。

環境設定

先把專案結構和 Python 虛擬環境準備好。

📁專案資料夾

建議把專案放在這個位置：

C:\Users\kodyf\Desktop\drone_simulation_project

🐍Python 虛擬環境

建立並啟用虛擬環境後，再安裝 MAVSDK：

py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install mavsdk
小提醒：如果 PowerShell 擋住腳本執行，可以先跑 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 再重新啟用虛擬環境。
